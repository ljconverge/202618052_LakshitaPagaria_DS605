# Lab 7: Image Representation, PCA, Eigenfaces and Face Recognition

## Overview

This assignment explores how face images can be represented as numerical vectors and how Principal Component Analysis (PCA) can reduce their dimensionality. The notebook builds eigenfaces, reconstructs images at different component counts, and evaluates face recognition using nearest-neighbour matching in the reduced space. It also compares the baseline with traditional machine-learning classifiers.

## Project Structure

- `202618052_Lab_7.ipynb`: Complete workflow for image inspection, PCA, eigenfaces, reconstruction, face recognition, and model comparison.
- `data/att_faces/`: Local copy of the AT&T Database of Faces (ORL), arranged in subject folders. The image files are excluded from Git.
- `data/att_faces/README`: Dataset description and attribution information.
- `figures/`: Plots generated by the notebook; excluded from Git.
- `results/`: Generated tables and saved PCA artifacts; excluded from Git.

## Dataset

- **Title:** AT&T Database of Faces (ORL)
- **Contents:** 40 subjects, with 10 grayscale images per subject. Each image is 112 x 92 pixels.
- **Expected layout:** `data/att_faces/s1/1.pgm` through `data/att_faces/s40/10.pgm`.
- **Attribution:** See `data/att_faces/README` for the dataset description and credit to Olivetti Research Laboratory.

The notebook expects the dataset to be available locally at `data/att_faces/`. The subject image folders are ignored by Git, so supply the dataset locally if it is not already present.

## Key Components

1. **Image inspection**
   - Load the PGM images and inspect their dimensions, intensities, and variation within and across subjects.
   - Visualize sample faces and intensity distributions.

2. **PCA and eigenfaces**
   - Convert each image to a flattened pixel vector, center the data, and compute principal components.
   - Compare covariance-based and SVD-based PCA results.
   - Visualize the mean face, leading and trailing eigenfaces, and explained variance.

3. **Reconstruction and recognition**
   - Reconstruct faces using different numbers of principal components and evaluate reconstruction quality.
   - Project images into PCA space and use nearest-neighbour matching to recognize subjects.
   - Examine accuracy as the number of components changes, including correct and incorrect matches.

4. **Model evaluation**
   - Compare nearest-neighbour baselines and traditional classifiers using cross-validation and held-out evaluation.
   - Save model comparison tables, accuracy summaries, reconstruction metrics, and split information.
